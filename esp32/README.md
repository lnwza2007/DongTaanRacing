# ESP32 MoTeC CAN Logger

เฟิร์มแวร์สำหรับ **ESP32** ในการดักจับข้อมูล CAN Bus จาก MoTeC M150 และ C125 บันทึกลง SD Card เป็นไฟล์ CSV และส่งค่าขึ้น HiveMQ Cloud (MQTT TLS) แบบ Real-time

---

## Hardware Configuration (การต่อสายไฟ)

### 1. VP230 Transceiver ──► ESP32
* ขา **3.3V** ของ VP230 ──► ต่อช่อง **3V3** ของ ESP32
* ขา **GND** ของ VP230 ──► ต่อช่อง **GND** ของ ESP32
* ขา **TX** ของ VP230 ──► ต่อเข้ากับขา **GPIO 5** ของ ESP32 (CAN TX)
* ขา **RX** ของ VP230 ──► ต่อเข้ากับขา **GPIO 4** ของ ESP32 (CAN RX)

### 2. SD Card Module ──► ESP32 (ผ่าน SPI)
* ขา **CS** ──► ต่อเข้าขา **GPIO 15**
* ขา **MOSI** ──► ต่อเข้าขา **GPIO 23**
* ขา **MISO** ──► ต่อเข้าขา **GPIO 19**
* ขา **SCK** ──► ต่อเข้าขา **GPIO 18**
* ขา **VCC** ──► ต่อเข้าขา **3V3** หรือ **5V**
* ขา **GND** ──► ต่อเข้าขา **GND**

## วิธีติดตั้งและอัปโหลดโปรแกรม (How to Upload)

โปรเจกต์นี้เขียนขึ้นสำหรับระบบ **PlatformIO** (ซึ่งทำงานภายใต้ VS Code)

### ขั้นตอนการอัปโหลดโค้ด:
1. เปิดโปรแกรม **VS Code** บนคอมพิวเตอร์ของคุณ
2. เข้าหน้าเมนู Extensions แล้วค้นหาชื่อ **"PlatformIO IDE"** ทำการกดติดตั้ง (Install)
3. ไปที่เมนู `File -> Open Folder` แล้วเลือกเปิดโฟลเดอร์ **`IC/esp32`**
4. เปิดไฟล์ **`src/config.h`** แล้วแก้ไขค่าการเชื่อมต่อให้ถูกต้อง:
   * แก้ไข `WIFI_SSID` และ `WIFI_PASSWORD` เป็นไวไฟของคุณ (เช่น ฮอตสปอตมือถือ)
5. เสียบสาย USB ระหว่าง ESP32 กับคอมพิวเตอร์
6. ทำการอัปโหลดโค้ด:
   * กดปุ่ม **Build (เครื่องหมายถูก ⚡)** ด้านล่างเพื่อคอมไพล์โค้ด
   * กดปุ่ม **Upload (ลูกศรขวา ➡️)** ด้านล่างเพื่อเริ่มเขียนโปรแกรมลงในชิป ESP32
7. กดปุ่ม **Serial Monitor (รูปปลั๊กไฟ 🔌)** เพื่อเปิดดูข้อมูลมอนิเตอร์จริง
